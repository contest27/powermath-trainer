# KI-Buddy — überall erreichbarer Hilfe-Knopf mit milder Mastery-Dämpfung

**Status:** APPROVED (2026-07-25)
**Datum:** 2026-07-25
**Projekt:** PowerMath Trainer (Builder, iPad-only PWA, no-build vanilla JS)

## Context

Letzter (und wertvollster) Facharzttrainer-Übernahme-Kandidat, Sebastians Wahl: ein überall erreichbarer schwebender „Buddy"-Knopf, der ein Bottom-Sheet mit KI-Chat öffnet — für schnelle Zwischenfragen. Kern-Kopplung: wird eine Übungsfrage **mit Buddy-Hilfe** gelöst, wird der Lernstand gedämpft. Baut auf dem gerade gebauten Streaming-Chat auf. Zwei Produkt-Entscheidungen mit Sebastian geklärt:

- **Dämpfung MILD:** mit Hilfe richtig gibt **halbe Gutschrift** auf den EWMA-Mastery-Score (halbiertes „richtig"-Gewicht). Die Wiederholung folgt **automatisch** dem Score-Band — kein harter Eingriff in den Zeitplan. **Sterne bleiben** (das Kind hat die Antwort produziert). Bestraft nie.
- **Reichweite: überall außer im Erklärungs-Screen** — FAB auf Today, Karte, während der Übungsfragen (dort mit „Hilf mir / Nebenfrage"-Wahl), und beim Anschauen (Watch). Im Erklärungs-Screen bleibt der bestehende qaBox (FAQ-Chips + Themen-Chat) — kein doppelter Einstieg.

**Ehrlicher Hinweis (Flaw B, bewusst):** Weil das Wiederholungs-Intervall in Bänder quantisiert ist (<60/≤85/>85 → 1/3/7 Tage), verschiebt eine *einzelne* mit-Hilfe-Antwort die nächste Wiederholung nur, wenn der kleinere Score-Zuwachs eine Band-Grenze unterschreitet — sonst gleiches Band, gleiches Intervall. Über den Sommer wirkt es kumulativ (der gedämpfte Score landet öfter in niedrigeren Bändern). Das ist genau, was „mild" bedeutet — der harte Clamp wurde bewusst abgelehnt.

## Architektur-Entscheidungen

1. **Chat-Extraktion (neues Leaf `js/ui/chat.js`):** `createChat({ ask, onExchange, placeholder }) → { el, thread, inputRow, addBubble }`. Die generische qaBox-Streaming-Schleife (thinking-Bubble, Akkumulation, Salvage-/Fehler-Zweige) wird verbatim herübergehoben; `ask(q,{onText})→Promise<string>` und `onExchange(q,a)` sind injiziert. `escapeHtml`/`friendlyTutorError` wandern mit. qaBox wird dünn (Chips + Key-Gate + `ask=askTutor({topic})`/`onExchange=logQa`); Buddy nutzt `ask=askTutor({system:buddySystemPrompt(ctx)})` + eigener Logger. **Byte-identisches qaBox-Verhalten.**
2. **Dämpfung — eine reine Mathe-Stelle:** `updateMastery(m, tier, ok, opts={})` — `w = ok ? (opts.assisted ? wRight/2 : wRight) : wWrong` (assisted wirkt nur auf den richtig-Fall; falsch bleibt falsch). Zähler: `m.correct += (ok && !assisted ? 1 : 0)`. `recordAttempt(...,opts)` reicht es durch + markiert den Ring-Puffer (`a:1`). Default `{}` = heute byte-identisch. **engine/ bleibt pur.**
3. **Signal `item.assisted`:** Buddy setzt bei „Hilf mir" **live beim Tap** `sess().items[sess().idx].assisted = true; store.save()`. `recordResult` liest `item.assisted` und ruft `recordAttempt(..., { assisted })`. Das Session-Objekt hat stabile Identität über rerender+persist (nur `buildSession`/`buildFocusSession` bauen es neu). Sterne unberührt (`s.results.push({ok:firstTryOk})` bleibt).
4. **Buddy-Modul `js/ui/buddy.js`:** `mountBuddy()` hängt den FAB (Inline-SVG, kein Emoji) einmal an `document.body` (außerhalb #root, das bei rerender geleert wird — wie `toast`). Sheet transient pro Öffnen (Muster `map.js stationSheet`, wiederverwendet `.sheet-scrim`/`.station-sheet` + `sheet-up`; Escape/Backdrop schließt). Intent-Zeile nur wenn `ctx.question` gesetzt; „Hilf mir" → Flag + `ctx.onAssist?.()`. Frischer Chat-Record pro Frage-ID, beim Reopen repliziert. Persistenz je Runde in `store.state.chats`. **Cross-Conversation-History-Browser im Sheet: verschoben** (Auswertung läuft über den Parent Corner).
5. **Router-Hook:** `core.js` bekommt `onAfterRender(fn)` (generisch, kein Buddy-Import); `rerender()` feuert es. `app.js`: `mountBuddy(); onAfterRender(updateBuddy)` vor `go('today')`. `updateBuddy()` liest `currentScreen()`+`sess()` und setzt Sichtbarkeit (`hasApiKey && Screen erlaubt`) + Kontext.
6. **Prompt:** `askTutor` bekommt optionalen `system`-Parameter (`system ?? systemPrompt(topic)`); pure `buildRequestBody(...)` extrahiert (testbar). Neu `buddySystemPrompt(ctx)`: kindgerecht, hilft v.a. Mathe, eine kurze Nebenfrage ok dann zurück zu Mathe, <90 Wörter, Plain Text; injiziert Themen-Titel + Frage-Stem (nur `q.prompt`, **nie `q.answer`**; „führe hin, gib nicht die Antwort").
7. **State:** `chats: []` top-level in `defaultState()` (Shallow-Merge migriert automatisch); `CHAT_CAP=100` in `save()` (via extrahiertem `capState()`); `exportJSON` nimmt es automatisch mit (nur apiKey gestrippt), `parseImport` round-trippt. Backup-only.
8. **Parent Corner:** neuer `section('AI buddy')` rendert `st.chats` gruppiert (🤝-Marker bei geholfen), getrennt vom qaLog.

## Sichtbarkeits-Matrix (`updateBuddy`)

| Screen / Phase | FAB | Intent | Grund |
|---|---|---|---|
| today, map | an | – | allgemeiner Helfer |
| session · explain | **aus** | – | qaBox besitzt den Chat |
| session · items (practice/review) | an | **ja** | Hilfe → flaggt `item.assisted` |
| session · items (**diagnostic**) | an | **nein** | Warm-up misst eigenständiges Können (struktureller Guard) |
| session · summary | **aus** | – | Feier-Screen |
| watch | **an** | – | allgemeiner Buddy (wie zugesagt „beim Anschauen") |
| parent / parentgate | aus | – | keine Kinder-Fläche |

**Diagnostik-Guard (Flaw A, strukturell):** in der Diagnostik setzt `updateBuddy` `view:'diagnostic'` **ohne** `question`/`onAssist` → der „Hilf mir"-Knopf erscheint nie → `item.assisted` kann an einem Diagnostik-Item nie gesetzt werden. Kein `recordResult`-Sonderfall nötig (sonst würde ein geholfener Treffer `d.correct++` aufblähen und den Prior verfälschen).

## Risiken / bewusste Entscheidungen

- **Flaw B** (Band-Quantisierung): frühere Wiederholung kumulativ/an Grenzen, nicht garantiert pro Antwort — inhärent am Band-Scheduler, = „mild". Kein Code-Change; ehrlich dokumentiert.
- **Flaw C**: `onAssist` liest das Item live beim Tap (kein stale Closure); `store.save()` deckt Reload der Tageslektion; Fokus-Sessions boot-cleared → kein Leck.
- **Minor**: „Hilf mir" *nach* dem Auflösen dämpft nicht rückwirkend (recordResult lief schon) — akzeptabel/gewollt (nur Hilfe vor dem Antworten zählt); Code-Kommentar.
- **Watch-FAB**: bewusst an (Zusage); falls im Sichttest störend, Ein-Zeilen-Rücknahme (`watch` aus der allowed-Liste).
